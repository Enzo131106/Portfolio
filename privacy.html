TRANSPARENCE & QUALITÉ WEB

Comment fonctionne ce portfolio ?

Ce portfolio est conçu en m'appuyant sur les principes de qualité numérique d'Opquast, avec l'objectif de proposer un site fonctionnel, sécurisé, accessible et respectueux des utilisateurs.

Données & confidentialité

Le portfolio n'utilise pas de dispositif de suivi publicitaire et ne collecte pas de données personnelles à des fins de profilage.

Le localStorage est uniquement utilisé pour mémoriser l'affichage de la fenêtre d'information sur la confidentialité.

Sécurité

Le site utilise notamment une Content Security Policy (CSP), des politiques de sécurité HTTP et le contrôle d'intégrité des ressources externes avec SRI.

Les ressources autorisées sont volontairement limitées afin de réduire les risques liés aux contenus externes.

Technologies

Le portfolio repose principalement sur HTML, CSS et JavaScript. Bootstrap et Bootstrap Icons sont utilisés pour l'interface, tandis que Three.js génère l'environnement 3D animé.

HTML CSS JavaScript Bootstrap Three.js

Chargement des ressources

Les librairies sont chargées depuis des CDN lorsque cela est possible. Des versions locales sont conservées dans le projet comme solution de secours.

Si le chargement d'une ressource externe échoue, le site peut utiliser automatiquement sa copie locale.

Cette démarche s'inscrit dans une volonté d'amélioration continue de la qualité du site, notamment sur les aspects de sécurité, de confidentialité, d'accessibilité et de fonctionnement technique.
