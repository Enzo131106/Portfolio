Confidentialité et fonctionnement

Cette page explique comment fonctionne mon portfolio et quelles données peuvent être utilisées lors de votre visite. Je m'appuie sur les bonnes pratiques d'Opquast pour améliorer le site.

Données personnelles

Le portfolio ne comporte ni compte utilisateur, ni formulaire de contact. Je n'utilise aucun outil de mesure d'audience, de suivi publicitaire ou de profilage.

Le site est hébergé sur GitHub Pages. GitHub enregistre les adresses IP des visiteurs à des fins de sécurité. Pour en savoir plus, consultez sa politique de confidentialité.

Stockage local

Le localStorage de votre navigateur conserve deux informations : la fermeture du message de confidentialité et votre meilleur score à Byte Invaders.

Ces informations ne sont pas envoyées à un serveur par le jeu ou la fenêtre de confidentialité. Elles n'ont pas de date d'expiration définie et peuvent être supprimées dans les paramètres de votre navigateur.

Le téléchargement du score crée une image directement sur votre appareil. Si vous choisissez de partager votre score, il est transmis à l'application que vous sélectionnez, ou copié dans votre presse-papiers.

Chargement des ressources

Les bibliothèques sont chargées depuis jsDelivr et la police Inter depuis Bunny Fonts. Ces services reçoivent les données techniques nécessaires aux connexions, notamment votre adresse IP.

Des copies locales des bibliothèques et de la police sont présentes dans le projet. Sur la page principale, elles servent de secours si le chargement externe échoue.

Les prestataires peuvent traiter certaines données en dehors de l'Union européenne. Leurs politiques de confidentialité précisent leurs pratiques respectives.

Contact et droits

Si vous me contactez, votre adresse e-mail, votre nom s'il est communiqué et votre message sont traités via Gmail pour répondre à votre demande, sur la base de mon intérêt légitime. Ils sont conservés le temps nécessaire aux échanges, sauf obligation légale ou besoin justifié.

Vous pouvez me contacter à enzo.camilo1306@gmail.com pour demander l'accès, la rectification, l'effacement ou la limitation du traitement de vos données, ou vous opposer à leur traitement lorsque ces droits s'appliquent.

Vous pouvez également adresser une réclamation à la CNIL. Les liens vers d'autres sites, dont LinkedIn et GitHub, sont soumis aux règles de confidentialité de ces sites.

Sécurité

Le site est accessible en HTTPS et utilise une Content Security Policy (CSP) pour limiter les sources de contenu autorisées.

Le contrôle d'intégrité (SRI) est utilisé sur certaines ressources externes pour vérifier qu'elles correspondent aux fichiers attendus.

Technologies

Le portfolio est développé en HTML, CSS et JavaScript. Bootstrap et Bootstrap Icons sont utilisés pour l'interface, Three.js pour le décor 3D et GSAP pour les animations.

Le code source est consultable sur GitHub.
