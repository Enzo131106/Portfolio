Confidentialité et fonctionnement

Cette page explique comment fonctionne mon portfolio et quelles données peuvent être utilisées lors de votre visite. Je m'appuie sur les bonnes pratiques d'Opquast pour améliorer le site.

Données personnelles

Le site ne comporte ni compte utilisateur, ni formulaire de contact, ni outil de mesure d'audience, de suivi publicitaire ou de profilage.

GitHub Pages héberge le site et GitHub enregistre les adresses IP à des fins de sécurité. Voir sa politique de confidentialité.

Sécurité

Le site utilise HTTPS et une Content Security Policy (CSP) pour limiter les sources de contenu autorisées.

Le contrôle d'intégrité (SRI) vérifie certaines ressources externes.

Technologies

Le portfolio utilise HTML, CSS et JavaScript, Bootstrap et Bootstrap Icons pour l'interface, Three.js pour le décor 3D et GSAP pour les animations.

Le code source est consultable sur GitHub.

Stockage local

Le localStorage mémorise la fermeture du message de confidentialité et votre meilleur score à Byte Invaders.

Ces données restent dans votre navigateur, sans expiration définie. Vous pouvez les supprimer dans ses paramètres.

L'image du score est générée sur votre appareil. Si vous partagez le score, il est envoyé à l'application choisie ou copié dans le presse-papiers.

Chargement des ressources

Les bibliothèques sont chargées depuis jsDelivr et la police Inter depuis Bunny Fonts. Ces services reçoivent des données de connexion, dont votre adresse IP.

La page principale utilise les copies locales des bibliothèques et de la police en cas d'échec du chargement externe.

Certaines données peuvent être traitées hors de l'Union européenne, selon les politiques de confidentialité de ces prestataires.

Contact et droits

Via Gmail, je traite votre adresse e-mail, votre nom si communiqué et votre message pour vous répondre (intérêt légitime). Ils sont conservés le temps des échanges, sauf obligation légale ou besoin justifié.
